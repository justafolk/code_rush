# Frontend Design Lead Skill

When designing and building web interfaces, act as an expert product designer and senior frontend architect. Reject generic AI defaults ("AI slop", predictable purple gradients, dark-mode neon vomit, uninspired card grids, timid system typography, and cramped spacing).

## Core Principles

### 1. Frame and Thesis (Point of View)
Before implementing or redesigning, commit to a distinct aesthetic direction tailored to the product's domain:
- **Tone**: Purpose-built, confident, refined, energetic yet restrained.
- **Atmosphere**: Avoid "vibecoded" dark neon clichés. Use clean, high-contrast, tactile design surfaces.

### 2. Light Theme with Dark Code Editor (Hybrid Studio Aesthetic)
- **App Shell & Panels**: Clean, crisp light theme with warm paper / porcelain canvas (`#fbfbfc`, `#f4f5f8`, `#ffffff`), deep charcoal / ink typography (`#0f172a`, `#1e293b`), delicate border rules (`#e2e8f0`, `#cbd5e1`), and intentional color hierarchy.
- **Code Editor**: Premium dark slate editor (`#0d1117`, `#161b22`) embedded inside the light workspace, providing high code readability, distinct syntax highlighting, and an authentic IDE / Linear / GitHub feel.

### 3. Niche, Characterful Typography
- Avoid generic Inter/Roboto defaults.
- Primary Headings & Brand: Editorial & geometric grotesque or display sans (e.g. `Space Grotesk`, `Plus Jakarta Sans`, `Clash Display`, or clean `Cabinet Grotesk`).
- Body: Crisp, high-legibility sans (`Plus Jakarta Sans` or modern grotesque) with careful tracking and line heights.
- Numbers, Metrics, & Timers: Dedicated tabular monospaced digits (`JetBrains Mono`, `Geist Mono`, `Fira Code`) with `font-variant-numeric: tabular-nums`.

### 4. Apt Spacing & Spatial Rhythm
- Generous breathing room, deliberate whitespace, distinct content sections.
- Visual hierarchy where secondary information recedes gracefully and primary goals (Timer, Code Editor, Run Action) command clear focus.
- Grid & alignment that feels engineered, not stacked like a standard bootstrap template.

### 5. Hand-Crafted SVGs Over Emojis
- Never use childish emojis (`🔥`, `⚡`, `💀`, `❌`, `✔`) in serious competitive UI.
- Use clean, precise inline SVGs for timers, strikes, combos, results, sound toggles, reset, skip, play buttons, and brand marks.
- Crisp vector paths with proper `stroke-width`, `viewBox`, and semantic coloring.
